# openFences

[English](README.md) | **Русский** | [简体中文](README.zh-CN.md)

> Лёгкая утилита для Windows, которая группирует значки рабочего стола. Открытая альтернатива Stardock Fences.

![platform](https://img.shields.io/badge/platform-Windows%2010%2F11-blue)
![lang](https://img.shields.io/badge/language-C%2B%2B17-%23f34b7d)
![license](https://img.shields.io/badge/license-MIT-green)

Этот репозиторий — форк [weiweigogo/openFrence](https://github.com/weiweigogo/openFrence) (MIT). Цели форка: документация на английском, русском и китайском, нормальная поддержка нескольких языков интерфейса (добавляем русский) и, в перспективе, порт на Linux (см. [Планы](#планы)).

---

## Возможности

- **Группировка значков** — на рабочем столе создаются полупрозрачные «панели» (fence) с эффектом матового стекла; значки перетаскиваются внутрь и группируются
- **Матовое стекло** — фон в стиле Acrylic: размытие с понижением разрешения, усиление насыщенности и шум, близко к внешнему виду Windows 11
- **Контекстное меню в стиле Windows 11** — собственная отрисовка Fluent Design: скруглённые углы, размытый фон, мягкая тень
- **Значок в трее** — новая панель, скрыть/показать всё, язык, автозапуск, ярлык на рабочем столе
- **Сохранение настроек** — расположение панелей, позиции значков и внешний вид хранятся в `%APPDATA%\Open Fences\config.json`
- **Несколько языков интерфейса** — английский, русский и китайский; по умолчанию язык берётся из Windows, а новый язык — это просто JSON-файл (см. [docs/LOCALIZATION.md](docs/LOCALIZATION.md), на английском)
- **Маленький размер** — один exe (~780 КБ), без зависимостей, не требует среды VC++, переносимый

## Быстрый старт

> **Безопасность.** Оригинальный автор закоммитил в репозиторий готовые `.exe`/`.dll`, в этом форке они удалены. Не запускайте готовые бинарные файлы из неизвестных источников, собирайте программу из исходников. Текущая версия не внедряет DLL в Explorer (каталог `experiments/legacy-hook` — неиспользуемый остаток раннего замысла).

1. Соберите программу из исходников (см. [Сборка](#сборка)).
2. Положите `openfences.exe` в любую папку и запустите.
3. Правый клик по значку в трее — язык, автозапуск, ярлык на рабочем столе.
4. Перетащите значки рабочего стола в панель.

> **Подсказка:** если значки рабочего стола скрыты и панели пропали, щёлкните правой кнопкой по значку в трее и выберите «Показать значки рабочего стола». Панели ждут на рабочем столе, пока список значков не вернётся.

## Сборка

```bash
# Требуется: Visual Studio 2017+ (с Windows 10 SDK), CMake 3.20+

git clone <этот репозиторий>
cd openFences
cmake -B build -G "Visual Studio 15 2017" -A x64
cmake --build build --config Release --target openfences
```

Результат: `build/Release/openfences.exe` (~780 КБ, CRT подключена статически).

│   │   ├── settings/          # панель настроек внешнего вида
│   │   ├── shell/             # рабочий стол и DPI, список значков рабочего стола, порядок сортировки Explorer
│   │   ├── tray/              # значок в области уведомлений и его меню
│   │   └── core/              # config.json, локализация, помощник для COM-указателей, идентификаторы ресурсов

├── tests/                     # модульные тесты (локализация, сетка значков, сортировка значков, фильтры изображения, полоса прокрутки)
├── experiments/legacy-hook/   # неиспользуемая DLL из раннего замысла
├── docs/                      # проектные заметки, LOCALIZATION.md, BUGS.md
├── CLAUDE.md                  # руководство для ИИ-ассистентов

## Настройки

Файл настроек: `%APPDATA%\Open Fences\config.json`

```json
{
  "version": 1,
  "language": "ru",
  "hideAll": false,
  "fences": [
    {
      "id": "f1",
      "title": "Программы",
      "x": 75, "y": 75,
      "w": 420, "h": 420,
      "collapsed": false,
      "icons": [ ... ],
      "bg": [0.08, 0.08, 0.10, 0.55],
      "titleColor": [0.05, 0.05, 0.07, 0.80],
      "fontSize": 18.0,
      "titleAlign": 0
    }
  ]
}
```

`language`: код языка (`en`, `ru`, `zh-CN`). Если ключа нет, язык берётся из Windows. Старые числовые значения (`0` — английский, `1` — китайский) преобразуются при загрузке.

## Технологии

- **Язык:** C++17
- **Окна:** Win32 `WS_CHILD` + `WS_EX_LAYERED` + `UpdateLayeredWindow`
- **Отрисовка:** Direct2D, DirectWrite, WIC
- **JSON:** [nlohmann/json](https://github.com/nlohmann/json)
- **Сборка:** CMake + MSVC (VS2017+), x64, статическая CRT (`/MT`)
